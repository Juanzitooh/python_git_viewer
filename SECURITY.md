# Security Policy

## Versoes com suporte

Foco de suporte de seguranca:

- branch `main`
- release estavel mais recente

Versoes antigas podem nao receber correcao.

## Como reportar vulnerabilidade

Nao abra vulnerabilidade sensivel em issue publica.

Use um canal privado:

- GitHub Security Advisory (preferencial), em:
  `Security` -> `Report a vulnerability` no repositorio.

Se o recurso nao estiver habilitado no momento, abra issue com titulo neutro pedindo contato privado.

## O que enviar no reporte

- descricao tecnica do problema
- impacto esperado
- passos de reproducao
- versao/commit afetado
- ambiente (SO, Python, distribuicao)

## Processo de triagem

- confirmacao inicial: ate 7 dias
- classificacao de severidade: apos reproducao
- correcao e release: conforme impacto e risco de exploracao
