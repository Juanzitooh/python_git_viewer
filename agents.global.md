# AGENTS Global

Antes de executar qualquer tarefa neste repositorio:

1. Leia o arquivo global do Codex em `/home/jp/.codex/AGENTS.md`.
2. Em demandas de roadmap, siga o protocolo em `/home/jp/.codex/guides/roadmap_docs_protocol.md`.
3. Fluxo operacional local: `roadmap.md` -> `docs/roadmap/agents.md` -> `docs/roadmap/status.md` -> `docs/roadmap/tasks.md`.
4. Trate `docs/roadmap/agents.md` como centro de operacoes do planejamento ativo.
5. A cada tarefa concluida, atualize `docs/roadmap/status.md`, `docs/roadmap/tasks.md` e `docs/roadmap/milestones.md`.
6. Arquive concluidas em `docs/roadmap/tasks.done.md` para manter backlog ativo enxuto.
7. Registre mudancas relevantes no `CHANGELOG.md`.

## Politica de commit/registro

- Commits atomicos com prefixos: `fix`, `feat`, `imp`, `docs`, `codex`.
- `fix`: confirmar com o usuario se o problema foi resolvido antes de commitar.
- `feat`, `imp`, `docs`, `codex`: registrar normalmente e seguir o fluxo.
